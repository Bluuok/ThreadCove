# 前端重设计：研究图谱

用户查看实际 Electron 界面后保留后端方向，明确要求重新设计前端，并进一步拆分展示与状态逻辑。原有海湾、纸白与森林绿风格不再作为本次方向；用户也拒绝普通工具风格列表，要求更多创意。

## 设计意图

以数字研究档案与线索图谱为视觉母题；用户最新指定低饱和雾蓝 / 灰蓝色系，替代初步提出的电光紫与酸橙黄。使用浅雾蓝纸面、灰蓝导航、深墨蓝文字和克制蓝色动作。采用档案标签、线索节点、批注式信息层级，形成可辨认的工作空间。首页允许有 CSS/SVG 图谱构图；会话中优先保留可读文本与输入区。

OpenDesign 使用本机 MCP 与 Local Codex，项目 `threadcove-precision-workspace-080b`。原型范围为桌面与响应式 Web、多个关联流程、精致产品界面。原型仅写入独立 OpenDesign 项目；实际应用代码由 Codex 负责移植。

## 实现边界

- 继续使用现有 ElectronAPI；后端、存储和传输协议不变。
- 会话状态与 API 交互提取为独立 hook；展示组件与设计变量分层。
- 保留发送、停止、任务切换草稿、模型设置、归档、来源与文件查看、权限响应和断线恢复。
- 用户自行生成图片；此次不调用图片生成服务，不引入未经提供的图片依赖。需要图像时另给用途、尺寸与提示词。
- 不将原型中的示例研究资料或运行状态冒充真实数据。

## 验收重点

真实 Electron、1440px Web 与 390×844 移动视口；检查首屏输入可达、无横向溢出、长标题/长文本、空态与会话态、抽屉/设置焦点和 Escape、真实本地 SSE 的发送/停止/恢复。
